파산확률은 현재 설정으로 앞으로 100라운드를 이론 확률(균등 5%) 하에 몬테카를로 돌린 결과입니다. 하우스 엣지 2%가 있으므로 라운드 수를 늘리면 파산확률은 단조 증가합니다.
이 도구는 예측기가 아니라 기록·검정 도구입니다. 104회 표본에서 셔플=비복원 가설은 기각됐고(슬라이딩 고유값 12.37 vs 덱모델 16.77), 마르코프 독립성·런검정·자기상관 모두 통과했습니다. 즉 조건부 확률은 항상 칸당 5%로 고정이며, 어떤 시점에 끊어도 기대 회수율은 0.98입니다. ②번 패널이 ALARM을 띄우기 전까지는 그 전제가 유효합니다.

저장소 설정

배포 파일 상단의 SUPABASE_URL/SUPABASE_KEY 상수가 기본값으로 쓰입니다. 여기 입력하면 이 브라우저에서만 그 값을 덮어씁니다. 둘 다 없으면 localStorage에만 저장됩니다.

Supabase SQL Editor에 아래를 1회 실행하세요:

create table if not exists shuffle_rounds (
  id         bigserial primary key,
  seed       text        not null,
  n          int         not null,
  idx        int         not null,
  mult       numeric     not null,
  created_at timestamptz not null default now()
);
create index if not exists shuffle_rounds_seed_n on shuffle_rounds(seed, n);
alter table shuffle_rounds enable row level security;
create policy "anon all" on shuffle_rounds
  for all to anon using (true) with check (true);
